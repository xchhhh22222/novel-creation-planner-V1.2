# 素材先行开书组装 V1.3

本文件定义“先用素材库确定一个故事核心，再给用户做选项”的备用路径。

## 1. 输入

分别读取：

1. 市场 structural lessons：只负责节奏和钩子；
2. DNA素材/02_金手指；
3. DNA素材/03_世界观；
4. DNA素材/04_修炼体系；
5. 人物/主支线/篇章/剧情机制素材。

## 2. 先过来源硬门

必须先取得：

- world_premise；
- primary_system；
- faction_ecology；
- resource_loop；
- 至少3个可用 golden_finger 候选。

来源不足时停止，不生成故事。

## 3. 只构造一个 shared_story_core

一个 core 至少明确：

- reader_promise；
- protagonist_baseline；
- world_premise；
- primary_system；
- faction_ecology；
- resource_loop；
- longline_problem；
- story_engine。

不得把三个不同素材组合分别扩成三本书。

## 4. 再做三个维度的选项

只做：

- 3个书名；
- 3个开篇结构；
- 3个金手指。

书名可以原创。
开篇来自市场 structural lessons。
金手指必须来自素材库，并标 DIRECT / ADAPT / HYBRID。

## 5. 用户选择后继续

用户未选时停止。

用户选定后：

- 冻结 selected_story_variant；
- 补 technique / artifact；
- 从素材中构造 strategic_target；
- 设计前100章两个高潮；
- 从高潮倒推。

## 6. 禁止

- 三个完整故事；
- 无来源金手指；
- 无来源世界核心；
- 市场样本直接变成新书设定；
- 为了凑3个选项原创第四种机制；
- 先写剧情后贴素材ID。
